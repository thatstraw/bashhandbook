# Contributing

Thanks for your interest in improving the Bash Scripting Handbook.

## Ways to Contribute

- Fix typos, grammar, or broken links
- Improve explanations, examples, and chapter flow
- Report unclear sections or technical mistakes
- Suggest better build, formatting, or publishing workflows

## Before You Start

- Open an issue or start a discussion for larger changes
- Keep changes focused and easy to review
- Preserve the existing tone: practical, concise, and example-driven

## Local Workflow

1. Fork the repository and create a branch for your changes.
2. Update the relevant files in `book/`, `README.md`, or supporting scripts.
3. If your change affects output, regenerate the PDF with `./create-book-pdf.sh`.
4. Verify links, formatting, and examples before opening a pull request.

## Content Guidelines

- Prefer short explanations backed by runnable examples
- Avoid unnecessary jargon when a simpler phrasing works
- Keep chapter structure and naming consistent with the rest of the book
- When correcting examples, favor portability and clarity

## Pull Requests

- Use a clear title and summary
- Explain what changed and why
- Include screenshots or generated output when helpful
- Mention any follow-up work that is intentionally left out

Thanks for helping make the handbook clearer and more useful.
