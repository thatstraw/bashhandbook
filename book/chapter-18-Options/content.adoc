= Bash Options

Bash options are configuration settings that modify the behavior of the shell or a script. You can enable or disable these options using the `set` builtin.

There are two main syntaxes to control options:

- `set -o option-name` or `set -option-abbrev` to **enable** an option.
- `set +o option-name` or `set +option-abbrev` to **disable** an option.

To enable an option **only when running a script**, you can do:

[source,bash]
----
bash -o option-name script.sh
# or
bash -option-abbrev script.sh
----

[NOTE]
====
Options affect how scripts behave and are critical when building reliable, secure, and predictable shell scripts.
====

== Common Bash Options

[cols="1,1,3",options="header"]
|===
| Abbreviation | Name | Effect

| `-B` | brace expansion
| Enable brace expansion (e.g., `{a,b,c}` becomes `a b c`). This is on by default.

| `+B` | brace expansion
| Disable brace expansion.

| `-C` | noclobber
| Prevent overwriting files via output redirection. You can still override with `>\|`.

| `-D` | — 
| Print double-quoted strings prefixed with `$` but **do not execute** commands. Used for debugging.

| `-a` | allexport
| Automatically export all variables as environment variables.

| `-b` | notify
| Notify when background jobs complete (not typically useful in scripts).

| `-c '...'` | —
| Read and execute commands from the given string instead of a script or stdin.

| — | checkjobs
| Warns about unfinished background jobs on shell exit. Enable with `shopt -s checkjobs`. Use with caution—it may hang!

| `-e` | errexit
| Exit the script if **any command** fails (non-zero exit status). Critical for robust scripting.

| `-f` | noglob
| Disable filename expansion (globbing) using wildcards like `*` and `?`.

| — | globstar
| Enable `**` for recursive globbing (e.g., `**/*.txt`). Enable with `shopt -s globstar`.

| `-i` | interactive
| Run the script in **interactive mode** (useful for REPL-like input).

| `-n` | noexec
| Don’t execute any commands—just check for syntax errors.

| `-o name` | —
| Enable the named shell option (like `pipefail` or `posix`).

| `-o posix` | POSIX mode
| Make Bash behave like a POSIX-compliant shell. Useful for portability.

| `-o pipefail` | pipe failure
| Make a pipeline return the exit code of the **first** failed command instead of the **last** one.

| `-p` | privileged
| Run the script with elevated privileges. Be very cautious with this!

| `-r` | restricted
| Enable **restricted mode**, limiting what the shell can do (e.g., no `cd` or `exec`).

| `-s` | stdin
| Read script input from stdin instead of a file.

| `-t` | onecmd
| Run just one command and exit.

| `-u` | nounset
| Treat **undefined variables** as errors and abort the script. Great for catching typos.

| `-v` | verbose
| Print each command to stdout **before** execution.

| `-x` | xtrace
| Print commands **and** their expanded arguments (useful for debugging).

| `-` | —
| End of options. Everything after this is treated as a positional parameter.

| `--` | —
| Unset all positional parameters. If arguments are given (`-- arg1 arg2`), positional parameters are set to them.
|===

[sidebar]
****
You can combine multiple options in one go:

[source,bash]
----
set -eux  # Exit on error, treat unset variables as errors, print commands
----
****

== Additional Bash Options

Bash includes extra optional behaviors that aren't controlled with `set`, but with another builtin: `shopt`. This command lets you enable or disable various shell behaviors that are especially useful in scripting and interactive use.

=== The `shopt` Builtin

Use `shopt` to view or modify these shell options.

[source,bash]
----
shopt [-pqsu] [-o] <OPTION...>
----

[NOTE]
====
- Use `-s` to **set** an option  
- Use `-u` to **unset** an option  
- Use `-p` to **print** all shell options and their status (default)
- Use `-q` to **query** quietly (exit status only, no output)
- Use `-o` to restrict to options also used by `set`
====

[IMPORTANT]
====
If you run `shopt -s nullglob`, then glob patterns that don’t match anything will expand to nothing instead of staying as-is. This is extremely helpful to avoid errors in loops.
====

=== Exit Code Behavior

When you list or change options using `shopt`, the command sets an appropriate exit status:

- **0 (true)** if the operation was successful (or all options are enabled when queried).
- **1 (false)** if one or more options are disabled or an unknown option was referenced.

.Example: Enable nullglob
[source,bash]
----
shopt -s nullglob
----

=== shopt Options Summary

[cols="1,3",options="header"]
|===
| Flag | Meaning

| `-s`
| Set (enable) the specified option(s)

| `-u`
| Unset (disable) the specified option(s)

| `-p`
| Print all shell options and their status (default)

| `-q`
| Quiet mode. Exit status reflects whether all named options are enabled

| `-o`
| Restrict options to those also accepted by `set`
|===

== Additional Shell Options

These are some of the most useful options you can enable with `shopt -s` or disable with `shopt -u`:

[cols="1,3",options="header"]
|===
| Option | Description

| `autocd`
| Allows you to type a directory name directly to `cd` into it, without using the `cd` command.

| `cdspell`
| Automatically corrects small typos in `cd` directory names (e.g. transposed characters, missing/extra letters).

| `checkjobs`
| Prevents the shell from exiting if there are running or stopped jobs. You must exit twice to leave.

| `dirspell`
| Enables spelling correction for directory names used in glob patterns.

| `dotglob`
| Makes glob patterns like `*` also match hidden files (those beginning with a dot).

| `nullglob`
| Causes globs that don't match any files to expand to nothing instead of remaining as-is.

| `failglob`
| Makes Bash throw an error if a glob pattern fails to match any files.

| `nocaseglob`
| Makes glob matching case-insensitive.

| `globstar`
| Enables the `**` pattern to recursively match files and directories.

|===

[sidebar]
----
To enable multiple options at once, you can list them:

[source,bash]
----
shopt -s dotglob nullglob globstar
----
----

====
For a full list of `shopt` options, check the https://www.gnu.org/software/bash/manual/html_node/The-Shopt-Builtin.html[official Bash manual].
====
